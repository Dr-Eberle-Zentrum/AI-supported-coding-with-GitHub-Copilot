# (1) Understanding a foreign script

We want to use a chat AI to get an idea what the following script does.

## (1.1) What prompt to use?

We want to use one prompt in different AI chat interfaces to investigate their differences.

- ? Formulate TOGETHER a prompt (without testing/using it) to get an idea what the script does!

  - *KEEP*: add your prompt to your log file
- ? What are important elements of the prompt?
  >> check the RECCE Prompt Checklist (via AI)

  - *KEEP*: add the final common prompt to your log file
  
## (1.2) Testing different AI platforms

- decide within the group who is using which chat AI (to test as many as possible)
- open a new chat with your AI of choice
- copy and paste the developed prompt along with the script file to your chat AI
  - *KEEP*: store the first answer of the script in your log file (for comparison)

Within the group:

- ? Let's have a look at the different outputs and compare!

# (2) Translating a foreign script

Now we want to translate the script into a familiar programming language of your choice!

## (2.1) Request a translation

- ? Design a prompt to get a rewrite of the script in a language of your choice.

## (2.2) Critical assessment

Think about the following questions?

- ? How much do you trust the created script (correctness, robustness, ..)?
- ? How could the script be improved?
- ? What are next steps in your translation attempt?

Discuss your issues with the AI and identify solutions

- *KEEP* in your log file:
